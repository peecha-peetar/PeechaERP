# فونت

طبق `docs/ui-ux-guidelines.md` بخش ۲، فونت پایه‌ی رابط کاربری **Vazirmatn** است
(متن‌باز، مجوز OFL): https://github.com/rastikerdar/vazirmatn

فایل‌های `.ttf` را از ریلیزهای همان مخزن دانلود و در همین پوشه با نام‌های زیر قرار دهید
(کد در `src/peecha/ui/app.py` همین نام‌ها را جست‌وجو می‌کند و در نبودشان به‌صورت
خودکار به فونت پیش‌فرض Kivy برمی‌گردد، پس نبودن فایل باعث کرش نمی‌شود):

```
Vazirmatn-Regular.ttf
Vazirmatn-Bold.ttf
```

این فایل‌های باینری عمداً در گیت کامیت نشده‌اند (حجم مخزن)؛ در فرآیند نصب/بیلد
دانلود می‌شوند.
