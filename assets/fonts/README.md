# فونت

فونتِ ترجیحیِ رابط کاربری (طبقِ استایلِ مرجعِ کاربر) **IRANSans** است؛ اگر
موجود نباشد به **Vazirmatn** (متن‌باز، مجوز OFL:
https://github.com/rastikerdar/vazirmatn) و در نهایت به Tahoma برمی‌گردد.

فایل‌های `.ttf` را در همین پوشه با یکی از این نام‌ها قرار دهید (کد در
`src/peecha/ui/main.py::_register_font` همین نام‌ها را جست‌وجو می‌کند و در
نبودشان خودکار به گزینه‌ی بعدی برمی‌گردد، پس نبودِ فایل باعثِ کرش نمی‌شود):

```
IRANSans-Regular.ttf
IRANSans-Bold.ttf
Vazirmatn-Regular.ttf
Vazirmatn-Bold.ttf
```

نکته: فقط فایلی که واقعاً نامِ خانواده‌اش (embedded font family) شاملِ
«iran»/«vazir» باشد پذیرفته می‌شود — یک فایلِ placeholder با نامِ درست اما
محتوایِ فونتِ دیگر، بی‌صدا رد و به گزینه‌ی بعدی برمی‌گردد.

این فایل‌های باینری عمداً در گیت کامیت نشده‌اند (حجم مخزن)؛ باید دستی در همین
پوشه قرار داده شوند.
