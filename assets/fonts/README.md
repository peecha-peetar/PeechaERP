# فونت

فونتِ ترجیحیِ رابط کاربری (طبقِ استایلِ مرجعِ کاربر) **IRANSans** است؛ اگر
موجود نباشد به **Vazirmatn** (متن‌باز، مجوزِ SIL OFL 1.1 -- متنِ کامل در
`OFL.txt` در همینِ پوشه؛ منبع: https://github.com/rastikerdar/vazirmatn) و
در نهایت به Tahoma برمی‌گردد.

از نسخه‌یِ R109 به بعد، فایل‌هایِ واقعیِ `Vazirmatn-Regular.ttf` و
`Vazirmatn-Bold.ttf` در همینِ پوشه commit شده‌اند (طبقِ درخواستِ صریحِ
کاربر برایِ یک فونتِ استاندارد/خواناترِ نمایشی -- چون Tahomaیِ واقعی یک
فونتِ اختصاصیِ مایکروسافت است، نه رویِ سرورهایِ لینوکس نصب است و نه مجازِ
به bundle‌شدن، پس در عمل فقط به فونتِ جایگزینِ سیستم بازمی‌گشت).

اگر بعداً فایل‌هایِ واقعیِ IRANSans هم در دسترس بود، می‌توان آن‌ها را هم با
همین نام‌ها در همین پوشه قرار داد؛ کد در
`src/peecha/ui/main.py::_register_font` این نام‌ها را جست‌وجو می‌کند و طبقِ
همان ترتیبِ اولویت (IRANSans -> Vazirmatn -> Tahoma) عمل می‌کند:

```
IRANSans-Regular.ttf
IRANSans-Bold.ttf
Vazirmatn-Regular.ttf   (موجود)
Vazirmatn-Bold.ttf      (موجود)
```

نکته: فقط فایلی که واقعاً نامِ خانواده‌اش (embedded font family) شاملِ
«iran»/«vazir» باشد پذیرفته می‌شود — یک فایلِ placeholder با نامِ درست اما
محتوایِ فونتِ دیگر، بی‌صدا رد و به گزینه‌ی بعدی برمی‌گردد.
