# پیچا (Peecha) — نرم‌افزار حسابداری/ERP

## تصمیمات معماری (تا این مرحله)

| موضوع | تصمیم |
|---|---|
| زبان برنامه‌نویسی | Python |
| فریم‌ورک UI | یک کدبیس واحد پایتون برای دسکتاپ + موبایل (Kivy / KivyMD) — محدودیت‌های گزارش‌سازی/چاپ پیچیده پذیرفته شده و بعداً با موتور گزارش جدا (مثلاً تولید PDF سمت سرور) جبران می‌شود |
| دیتابیس | SQL Server 2016 (T-SQL، از قابلیت‌های 2016 مثل System-Versioned Temporal Tables و JSON بومی استفاده می‌شود) |
| چند‌شرکتی | هر رکورد تجاری به `CompanyID` وصل است؛ کاربر می‌تواند به چند شرکت دسترسی داشته باشد |
| چند‌ارزی | هر شرکت یک ارز پایه دارد؛ نرخ تبدیل روزانه در `core.ExchangeRates` |
| چند‌زبانه | بجای ستون‌های ثابت `NameFa`/`NameEn` در هر جدول، از جدول عمومی `core.Translations` استفاده می‌شود تا افزودن زبان جدید نیاز به تغییر ساختار دیتابیس نداشته باشد |
| سیستم دسترسی | RBAC درختی (نقش از نقش والد ارث‌بری می‌کند) روی سه سطح منو/فرم/فیلد، با اکشن‌های مجزا (مشاهده، ایجاد، ویرایش، حذف، چاپ، خروجی، تایید)، و امکان تخصیص نقش جداگانه به‌ازای هر ماژول برای یک کاربر — جزئیات در `docs/permission-model.md` |
| ماژول در دست ساخت | حسابداری (دفتر کل) — جزئیات در `docs/accounting-module.md` |

## ساختار

```
db/schema/    اسکریپت‌های DDL دیتابیس (به ترتیب شماره اجرا می‌شوند)
docs/         مستندات تصمیمات معماری
```

قدم‌های بعدی با نظر مشاور پروژه (شما) مشخص می‌شود.
