# رابطِ کاربریِ پیچا (Qt6 / PySide6)

طبقِ تصمیمِ مهاجرت (RTL/فارسیِ Kivy روی ویندوز حتی با اصلاح هم قابل‌اتکا
نبود، مخصوصاً هنگامِ تایپِ زنده)، کلِ رابطِ کاربری با Qt6 بازنویسی شد.
نسخه‌ی قدیمیِ Kivy از پروژه حذف شده است.

## اجرا

```
pip install -e .
python -m peecha.ui.main
```

(نیازمندِ یک دیتابیسِ راه‌اندازی‌شده — همان تنظیماتِ محیطیِ `PEECHA_DB_*`.)

## ساختار

- `main.py` — نقطه‌ی ورود؛ فونت/جهت/استایلِ سراسری را تنظیم می‌کند.
- `theme.py` — پالتِ رنگی + QSSِ سراسری.
- `login_window.py` / `shell_window.py` — ورود و پوسته‌ی اصلی (نوارِ کناری + هدر + ناوبری).
- `screens/` — هر صفحه یک QWidget با متدِ اختیاریِ `refresh()`.
