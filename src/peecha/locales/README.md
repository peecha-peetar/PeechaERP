# فایل‌های ترجمه (i18n)

هر فایل در این پوشه یک کاتالوگِ ترجمه برای یک زبان است: `<کدِ زبان>.json`
(مثلاً `en-US.json`) — یک دیکشنریِ تخت `{"متنِ فارسیِ منبع": "ترجمه"}`.

- این فایل‌ها **خودکار** ساخته می‌شوند: به‌محضِ تعریفِ یک زبانِ تازه از صفحه‌ی
  «زبان‌ها»، فایلِ همان زبان با `services/i18n_translations.py` تولید
  می‌شود (`generate_translation_file`).
- `_source.json` فهرستِ منبعِ (فارسی) همه‌ی متن‌های قابل‌ترجمه است — هر بار
  برنامه بالا می‌آید، این فهرست و به‌تبعش فایلِ هر زبانِ موجود با
  `SOURCE_STRINGS`ی جدیدِ کدِ برنامه هم‌گام می‌شود (`regenerate_all`)، تا
  فرم‌های تازه‌ای که در آینده اضافه می‌شوند هم در فایل‌های ترجمه ظاهر شوند.
- برای اصلاحِ دستیِ یک ترجمه: همین فایل‌های JSON را مستقیم ویرایش کنید
  (مقدارِ هر کلید را عوض کنید) — تغییرات با راه‌اندازیِ بعدیِ برنامه
  (یا با ورود دوباره به همان زبان) اعمال می‌شود.
- زبانِ پیش‌فرض (فارسی) فایل ندارد چون ترجمه‌اش خودِ متن است.
- ترجمه فقط شاملِ متن‌های ثابتِ رابط کاربری است (عنوانِ فرم‌ها، برچسبِ
  فیلدها، دکمه‌ها، پیام‌ها) — هرگز شاملِ اطلاعاتِ واردشده‌ی کاربر (نامِ
  حساب/شرکت/کاربر و مانند آن) نیست.
