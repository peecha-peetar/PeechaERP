# نمونه‌ی آزمایشیِ Qt6 (PySide6)

هدف: سنجشِ کیفیتِ RTL/فارسیِ Qt6 در برابرِ Kivy، قبل از تصمیمِ نهایی برایِ
بازنویسیِ کاملِ رابطِ کاربری. فقط دو صفحه ساخته شده — ورود + فهرستِ
حساب‌ها — و از همان لایه‌ی سرویس/دیتابیسِ موجود (`peecha.services.*`)
استفاده می‌کند؛ هیچ تغییری در بک‌اند لازم نبود.

## نتیجه

Qt6 بدونِ هیچ کدِ دستیِ reshape/bidi (که در Kivy برایِ `rtl.py` و
`font_direction`/`font_script_name` لازم بود)، متنِ فارسی را درست
می‌چسباند، جهتش را درست نمایش می‌دهد، و حتی ترتیبِ ستون‌های جدول را با
فقط یک خط (`app.setLayoutDirection(Qt.RightToLeft)`) خودش برعکس می‌کند —
بدونِ نیازی به تکنیکِ «ترتیبِ معکوسِ اعلامِ فرزندان» که در KV/BoxLayoutِ
Kivy برایِ هر ردیف/هدر لازم بود.

## اجرا

```
pip install PySide6
python -m peecha.qt_pilot.main
```

(نیازمندِ یک دیتابیسِ راه‌اندازی‌شده — همان تنظیماتِ محیطیِ
`PEECHA_DB_*` که برایِ برنامه‌ی اصلی استفاده می‌شود.)

PySide6 عمداً به `requirements.txt`/`pyproject.toml` اضافه نشده — این
یک نمونه‌ی جداگانه برایِ تصمیم‌گیری است، نه بخشی از برنامه‌ی اصلی.
