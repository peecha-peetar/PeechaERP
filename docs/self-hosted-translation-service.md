# راه‌اندازیِ محلیِ سرویسِ ترجمه (LibreTranslate)

## چرا self-host؟

صفحه‌ی «ترجمه‌ها» به‌طورِ پیش‌فرض به سرورِ عمومیِ `https://libretranslate.com`
وصل می‌شود. این سرور برای جلوگیری از سوءاستفاده الان به کلیدِ API نیاز
دارد (پیامِ خطای «۴۰۰ Bad Request ... to get an API key» دقیقاً همین را
می‌گوید). یک نسخه‌ی **self-hosted** (روی سیستمِ خودتان با Docker) کاملاً
رایگان و بدونِ محدودیت است، به هیچ کلیدی نیاز ندارد، و کاملاً تحتِ کنترلِ
خودتان می‌ماند — دقیقاً همان چیزی که از اول (LibreTranslate متن‌باز/رایگان)
خواسته بودید.

## پیش‌نیاز

نصبِ Docker Desktop (ویندوز/مک) یا Docker Engine (لینوکس) —
راهنمای رسمی: https://docs.docker.com/get-started/get-docker/

## مراحلِ اجرا

۱. ترمینال/PowerShell را در پوشه‌ی ریشه‌ی همین پروژه (کنارِ همین فایل) باز
   کنید.

۲. این دستور را اجرا کنید:

   ```
   docker compose -f docker-compose.libretranslate.yml up -d
   ```

   بارِ اول چون باید مدل‌های زبان دانلود شوند، ممکن است چند دقیقه طول
   بکشد و به اینترنت نیاز دارد — فقط همین یک‌بار. دفعاتِ بعد فوری بالا
   می‌آید.

۳. برای اطمینان، مرورگر را باز کنید و به آدرسِ زیر بروید — باید صفحه‌ی
   وبِ LibreTranslate را ببینید:

   ```
   http://localhost:5000
   ```

۴. در برنامه‌ی پیچا، به صفحه‌ی «ترجمه‌ها» (زیرِ مدیریتِ سیستم) بروید:
   - فیلدِ «آدرسِ سرویسِ ترجمه» را به `http://localhost:5000` تغییر دهید
   - فیلدِ «کلیدِ API» را خالی بگذارید (لازم نیست)
   - دکمه‌ی «ترجمه با سرویسِ آنلاین» را بزنید

## توقف / راه‌اندازیِ دوباره

```
docker compose -f docker-compose.libretranslate.yml down    # توقفِ کامل
docker compose -f docker-compose.libretranslate.yml up -d   # راه‌اندازیِ دوباره
```

مدل‌های دانلودشده در یک volume نگه داشته می‌شوند، پس دفعه‌ی بعد نیازی به
دانلودِ دوباره نیست (مگر خودِ volume را هم پاک کنید).

## افزودنِ زبان‌های بیشتر

فایلِ `docker-compose.libretranslate.yml` فقط ۶ زبان را بارگذاری می‌کند
(`LT_LOAD_ONLY=en,fa,ar,fr,de,tr`) تا حجمِ دانلود/دیسک زیاد نشود. اگر
زبانِ دیگری در برنامه تعریف کردید که در این فهرست نیست، کدِ آن زبان
(دو حرفی، مثلاً `es` برای اسپانیایی) را به همین فهرست اضافه کنید و
کانتینر را دوباره بسازید:

```
docker compose -f docker-compose.libretranslate.yml up -d --force-recreate
```

## نکاتِ مهم

- این سرویس فقط وقتی کار می‌کند که کانتینرِ Docker روشن باشد.
- حجمِ مدل‌ها برای همین ۶ زبانِ پیش‌فرض حدودِ ۱ تا ۲ گیگابایت است.
- این سرویس فقط روی همان سیستمی که Docker را اجرا کرده‌اید در دسترس است
  (`localhost`). اگر برنامه روی سیستمِ دیگری اجرا می‌شود، به‌جای
  `localhost` باید آدرسِ IP سیستمِ سرور را بگذارید و پورتِ ۵۰۰۰ در
  فایروال باز باشد.
